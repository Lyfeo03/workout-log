# 运动打卡 · 网页版

有氧 / 无氧训练记录，纯前端单文件应用，数据只保存在使用者自己的浏览器里。

- 有氧：跑步、跑步机爬坡、游泳、骑行等 12 种项目，记录时长与消耗卡路里
- 无氧：48 个健身房动作，按「重量 kg × 次数」逐组记录
- 统计：连续天数、累计容量、肌群分布、e1RM 个人记录
- 模板：把常练的动作存成模板，一键带出上次重量
- 数据导出 / 导入 JSON 备份

## 使用

直接打开 Pages 地址即可。手机上用浏览器菜单「添加到主屏幕」，就能像 App 一样使用。

⚠️ 数据存在各自设备的浏览器 localStorage 中，换设备或清缓存前请先在「我的」页导出备份。
